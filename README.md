# BeloSprint

Aplicação web simples para testes de uma organização focada em conhecimento, liderança e inovação.

## Recursos

- Seção de recomendação de livros.
- Seção de notícias e tendências.
- Formulário de inscrição em aulas com líderes.
- Botões de acesso para comunidades com diferentes níveis de verificação.

## Executar localmente

```bash
python3 -m http.server 8000
```

Abra `http://localhost:8000` no navegador.
